# Security Policy

## Підтримувані версії

Поки проєкт не має стабільного релізу 1.0/production, виправлення безпеки застосовуються лише до поточної гілки `main`.

## Повідомлення про вразливість

Не публікуйте деталі потенційної вразливості у відкритому issue до узгодження виправлення.

У повідомленні вкажіть:

- компонент і версію;
- умови експлуатації;
- можливий вплив;
- мінімальний сценарій відтворення;
- запропоноване виправлення, якщо воно відоме.

## Модель довіри

Колектори виконуються локально від `root`, тому зміни до shell scripts, systemd units та installer вважаються security-sensitive. Pull request із такими змінами повинен проходити окремий review.
