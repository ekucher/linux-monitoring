# Політика безпеки

## Підтримувані версії

Виправлення безпеки готуються для поточної production-версії та актуальної гілки `main`.

Підтримуване середовище:

- Debian 13;
- Proxmox VE 8;
- Zabbix Agent 2 7.4.

Робота на інших платформах або версіях не вважається перевіреною конфігурацією.

## Повідомлення про вразливість

Не публікуйте деталі потенційної вразливості у відкритому issue до узгодження виправлення.

У повідомленні вкажіть:

- компонент і версію;
- підтримувану платформу, на якій відтворено проблему;
- умови експлуатації;
- можливий вплив;
- мінімальний сценарій відтворення;
- запропоноване виправлення, якщо воно відоме.

Не додавайте до повідомлення реальні паролі, токени, серійні номери, приватні адреси або інші секретні дані.

## Модель довіри

Колектори, updater та інсталятор можуть виконуватися від `root`. Тому зміни до shell scripts, systemd units, конфігурації Zabbix Agent 2 та `install.sh` вважаються критичними з погляду безпеки.

Такі зміни повинні:

- проходити окремий review;
- не виконувати зовнішній код;
- не завантажувати неперевірені файли під час збору метрик;
- використовувати мінімально необхідні права;
- зберігати JSON cache атомарно;
- не виводити секретні або надлишкові апаратні ідентифікатори без необхідності.
