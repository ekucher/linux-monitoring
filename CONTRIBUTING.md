# Участь у розробці

## Основні правила

Проєкт орієнтований виключно на production-використання з Debian 13, Proxmox VE 8 і Zabbix Agent 2 7.4.

До репозиторію дозволено додавати лише компоненти, які одночасно:

- повністю реалізовані;
- протестовані автоматично, де це можливо;
- перевірені вручну на реальному обладнанні;
- задокументовані українською мовою;
- готові до безпечного використання у production.

Заборонено додавати порожні модулі, placeholder, TODO-модулі, демонстраційні заглушки та шаблони майбутніх колекторів.

## Робочий процес

1. Створіть окрему гілку від `main`.
2. Вносьте одну логічну зміну на pull request.
3. Перед push виконайте:

```bash
make test
find . -type f -name '*.sh' -print0 | xargs -0 shellcheck --severity=warning
find . -type f -name '*.sh' -print0 | xargs -0 shfmt -d -i 4 -ci
```

4. Не змінюйте формат наявних JSON-полів без підвищення `schema_version`.
5. Не змінюйте поточну структуру каталогів лише заради підготовки до майбутніх модулів.

## Вимоги до нового колектора

Новий колектор можна додавати лише після завершення реалізації та production-перевірки. Він повинен:

- бути незалежним від Zabbix під час збору даних;
- виводити один валідний JSON у stdout;
- писати діагностику лише у stderr;
- не змінювати систему під час звичайного збору;
- мати updater, service, timer, Zabbix Agent Alias і шаблон Zabbix;
- мати автоматичні та ручні сценарії перевірки;
- бути перевіреним на реальному обладнанні;
- мати повну документацію українською мовою.

До виконання всіх цих умов колектор не додається до репозиторію навіть у вимкненому вигляді.

## Повідомлення комітів

Використовуйте короткі повідомлення у стилі Conventional Commits. Технічний префікс не перекладається, опис може бути українською:

```text
feat: додати перевірений колектор
fix: зберігати SMART cache при помилці збору
ci: додати перевірку ShellCheck
docs: уточнити підтримку RAID-контролерів
```

## Контрольний список pull request

- [ ] Зміна стосується підтримуваних production-платформ.
- [ ] Компонент повністю реалізований і не є заготовкою.
- [ ] `bash -n` проходить для всіх shell scripts.
- [ ] ShellCheck не повертає помилок.
- [ ] shfmt не знаходить відмінностей.
- [ ] JSON перевірено через `jq -e`.
- [ ] Zabbix YAML імпортується у Zabbix 7.4.
- [ ] Проведено перевірку на реальному обладнанні.
- [ ] Документацію оновлено українською мовою.
- [ ] Зворотну сумісність оцінено.
