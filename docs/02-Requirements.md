# 2. Вимоги

## Підтримувані системи

Проєкт підтримує виключно такі production-платформи:

- Debian 13;
- Proxmox VE 8;
- Zabbix Agent 2 7.4.

Інші версії Debian, Proxmox VE, Zabbix Agent, Ubuntu та інші дистрибутиви не входять до підтримуваної конфігурації, доки їх не буде окремо реалізовано, протестовано, задокументовано та перевірено на реальному обладнанні.

## Обов'язкові компоненти

- права `root` або можливість виконання через `sudo`;
- `systemd`;
- Zabbix Agent 2 версії 7.4;
- доступ Zabbix Server або Zabbix Proxy до TCP 10050;
- `jq`.

## SMART

- `smartmontools`;
- прямий доступ операційної системи до накопичувачів або перевірена конфігурація RAID/HBA;
- накопичувачі SATA, SAS або NVMe, які коректно обробляє `smartctl`.

## Sensors

- `lm-sensors`;
- відповідні модулі ядра, наприклад `coretemp`, `k10temp` або `nct6775`;
- попередня перевірка доступних показників командою `sensors`.

Не всі системні плати експортують дані про вентилятори, напруги або потужність. Відсутність конкретного показника не є помилкою колектора, якщо `sensors` також не повертає цей показник.

## Межі підтримки

Наявність колектора у репозиторії означає, що він підтримується, протестований і готовий до production-використання. Наразі підтримуються лише колектори SMART і Sensors.
